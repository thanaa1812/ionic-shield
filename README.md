# الدرع الأيوني — Ionic Shield

صفحة تعريف ومعلومات تواصل لمشروع **الدرع الأيوني** من شركة **أساليب الابتكار**،
يُوصل إليها عبر باركود في نهاية العرض التقديمي.

**الرابط:** https://thanaa1812.github.io/ionic-shield/

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة كاملة (تصميم + محتوى + سكربت النسخ) |
| `contact.vcf` | بطاقة اتصال تُحفظ في جهاز الزائر |
| `fonts.css` | تعريف خط IBM Plex Sans Arabic |
| `assets/` | ملفات الخط والأيقونة |

## قيد الإكمال

هذه العناصر معطّلة داخل `index.html` (معلّقة كتعليقات HTML) وتُفعّل عند توفر محتواها:

- نبذة المشروع — بانتظار الصياغة المعتمدة
- المسمى الوظيفي
- زر السيرة الذاتية — بانتظار `cv.pdf`
- زر لينكدإن — بانتظار الرابط

## التعديل

عدّل `index.html` ثم:

```bash
git add -A && git commit -m "تحديث المحتوى" && git push
```

الرابط لا يتغير أبداً، فالباركود المطبوع يبقى صالحاً.
